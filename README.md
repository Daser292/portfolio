 ### Currency Fetcher Service

Автоматизированный сервис для получения и сохранения курсов валют.

Разработал Python-скрипт, который:
- Запрашивает курсы валют (USD → RUB, USD → EUR) с публичного API каждые N минут
- Сохраняет данные в PostgreSQL (две связанные таблицы с внешним ключом)
- Логирует ошибки подключения и таймауты в отдельный файл
- Содержит SQL-запрос с JOIN для анализа истории запросов

**Архитектура:**
- Планировщик на библиотеке schedule
- Работа с БД через psycopg2
- Обработка ошибок API (таймауты, недоступность сервера)
- Конфигурация через переменные окружения

- Технологии: Python, PostgreSQL, Docker, REST API
